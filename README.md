# Aadi Tyagi — Full Stack Developer Portfolio

Welcome to the official repository for **Aadi Tyagi's Personal Portfolio**.

## 🌟 Overview
A clean, responsive, multi-page portfolio built with high-performance vanilla HTML, CSS, and modern JavaScript. Inspired by clean developer aesthetics, featuring:
- **Theme Toggle:** High-contrast Dark & Light mode with `localStorage` memory and system preferences support.
- **Micro-Animations & Parallax:** Lightweight custom SVG vector storytelling with mouse-interactive 3D parallax tilt.
- **Directional Scroll Reveals:** 60 FPS viewport transitions powered by `IntersectionObserver`.
- **Live Production Applications:** Showcasing live enterprise ERPs, developer platforms, and full-stack systems.
- **Production Ready:** Pre-configured with `vercel.json` for one-click deployment with clean URLs and security headers.

---

## 🛠️ Tech Stack
- **Frontend:** Vanilla HTML5, Semantic CSS3 (CSS Custom Properties & Grid), ES6+ JavaScript
- **Typography:** Poppins, Caveat, Plus Jakarta Sans
- **Icons:** FontAwesome 6 Free CDN
- **Deployment:** Vercel (`vercel.json`)
- **Contact Service:** FormSubmit AJAX integration
